# OXYGEN GYM

الموقع الرسمي لنادي أوكسجين جيم في طرابلس، ليبيا (واجهة عامة + لوحة إدارة).

## التشغيل محلياً

**المتطلبات:** Node.js

1. تثبيت الحزم:
   `npm install --legacy-peer-deps`
2. انسخ `.env.example` إلى `.env` وضع قيمة قوية لـ `JWT_SECRET`
3. شغّل التطبيق:
   `npm run dev`

السيرفر يعمل على `http://localhost:3000`.

حسابات الإدارة الافتراضية عند أول تشغيل: `manager` / `waleed` / `ali` — غيّر كلمة المرور من لوحة الإدارة فوراً.
